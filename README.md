# AddRoundKey · Operaciones con matrices

Ejercicio de la operación XOR entre una matriz de estado y una clave de ronda.

## Archivo principal

[`Add round key.py`](<Add round key.py>) contiene el ejercicio. El repositorio conserva su nombre histórico para mantener los enlaces existentes.

## Qué permite revisar

Lee el punto de entrada, los datos de ejemplo y el resultado de la operación. Contrasta los datos de entrada con la salida antes de extender el ejercicio.

## Alcance

Este ejercicio muestra una operación de AES; no implementa por sí solo un sistema completo de cifrado seguro.

## Ejecutar

```powershell
python "Add round key.py"
```
